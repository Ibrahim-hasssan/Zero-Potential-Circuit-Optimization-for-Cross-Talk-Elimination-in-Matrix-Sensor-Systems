# Zero Potential Circuit Optimization for Cross-Talk Elimination in Matrix Sensor Systems

## Overview

This project investigates the use of an Alternating Current Zero Potential Circuit (AC-ZPC) for accurate impedance measurement in two-dimensional sensor arrays.

The main objective is to reduce measurement errors caused by crosstalk and non-ideal circuit components while enabling accurate frequency-domain sensor characterization.

The project combines:

- LTspice circuit simulation
- Python-based simulation automation
- FFT-based signal analysis
- Multiple excitation signal techniques
- Resistance and impedance calculation
- STM32H7B0VBTx embedded implementation
- Real-time sensor data acquisition and processing

---

## Project Objectives

The project focuses on:

1. Investigating crosstalk in 2-D resistive and impedimetric sensor arrays.
2. Evaluating the Alternating Current Zero Potential Circuit (AC-ZPC) measurement method.
3. Automating LTspice simulations using Python.
4. Evaluating different excitation signals using frequency-domain analysis.
5. Characterizing the operational frequency range of the sensor interface.
6. Implementing real-time signal acquisition and FFT-based processing on an STM32 microcontroller.

## AC-ZPC Measurement Principle

Two-dimensional sensor arrays can suffer from crosstalk caused by unintended current paths through neighboring sensors.

The AC-ZPC approach uses frequency-division multiplexing to separate sensor responses in the frequency domain.

Each sensor row can be excited using a different frequency. The resulting column signal contains the frequency components from the different rows. FFT analysis can then be used to isolate the response associated with a specific sensor.

For a resistive sensor, the resistance can be calculated from the ratio between the input and output signal amplitudes:

$$
R_{mn} = R_{ref}\frac{A_m}{B_{mn}}
$$

where:

- $R_{mn}$ is the sensor resistance
- $R_{ref}$ is the reference resistor
- $A_m$ is the input signal amplitude
- $B_{mn}$ is the measured output amplitude

For impedimetric sensors, both magnitude and phase information can be used to determine the sensor impedance and its resistive and capacitive components.

## Frequency Response Analysis

An AC analysis was performed over a frequency range of **1 Hz to 15 kHz** to characterize the frequency response of the sensor interface.

The main limitation at higher frequencies was the phase deviation introduced by the operational amplifier.

A maximum phase deviation of approximately **2°** was defined as the acceptable limit.

The phase response reached this limit at approximately **13 kHz**.

Therefore:

> **Recommended operational frequency: below 13 kHz**

The output magnitude remained relatively stable over the investigated range, while phase deviation became the main limiting factor at higher frequencies.

---

## Excitation Signal Analysis

Several excitation signals were investigated to evaluate the robustness of the measurement methodology.

### 1. Single-Sine Excitation

A sinusoidal excitation signal was used as the basic measurement method.

The analysis used a **5 kHz** excitation frequency with an amplitude of **0.5 V**.

FFT analysis was applied to the output signal to determine the magnitude of the response at the fundamental frequency.

The measured resistance deviation remained below approximately **0.03%** over the tested resistance range.

### 2. Multi-Sine Excitation

A multi-sine signal was generated by combining four sinusoidal components:

- 500 Hz
- 1 kHz
- 2.5 kHz
- 5 kHz

The output signal contains multiple frequency components, so FFT analysis was used to isolate the desired frequency component.

The measured deviation remained approximately within:

**±0.08%**

### 3. Square-Wave Excitation

A square-wave excitation signal was investigated as a broadband excitation method.

A square wave contains the fundamental frequency and odd harmonics. Therefore, frequency-domain analysis was used to isolate the fundamental component.

The square-wave test used a fundamental frequency of **5 kHz**.

The measured deviation generally remained within:

**±0.06%**

### 4. Linear Chirp Excitation

A Linear Chirp Signal (LCS) was used to investigate the system over a continuously changing frequency range.

Unlike a single-frequency excitation, the chirp signal sweeps through a range of frequencies over time.

FFT analysis was applied to the input and output signals to evaluate their frequency-domain characteristics.

The measured deviation remained approximately within:

**0% to -0.04%**

### 5. DIBS Excitation

A DIBS (Delay and Doppler Invariant Binary Sequence) signal was investigated as a complex broadband, digital-like excitation signal.

The input and output signals were transformed into the frequency domain using FFT.

A selected frequency component was then used for the resistance calculation.

The measured deviation was primarily within:

**+0.01% to -0.07%**

## Hardware Implementation

A hardware prototype was implemented using the **STM32H7B0VBTx** microcontroller.

The embedded system performs:

- AC signal generation
- Sensor selection
- ADC signal acquisition
- DMA-based data transfer
- FFT processing
- Frequency-component extraction
- Impedance calculation
- Calibration
- Sensor matrix scanning
- UART data transmission

The hardware system uses external analog multiplexers for sensor selection and operational amplifiers for the sensor interface.

---

## Real-Time DSP Processing

The embedded processing pipeline is:

```text
Sensor Excitation
      │
      ▼
Sensor Matrix
      │
      ▼
ADC Acquisition
      │
      ▼
DMA Data Transfer
      │
      ▼
FFT Processing
      │
      ▼
Frequency Component Extraction
      │
      ▼
Impedance Calculation
      │
      ▼
Polynomial Calibration
      │
      ▼
2-D Impedance Map
      │
      ▼
UART → Host PC
```

The captured voltage and current signals are processed using FFT algorithms implemented with the **CMSIS-DSP** library.

The required frequency components are extracted from the FFT results and used to calculate the sensor impedance:

$$
Z = \frac{V}{I}
$$

A polynomial calibration function is then applied to compensate for non-idealities in the practical measurement system.

---

## Calibration

Real-world circuit components introduce additional measurement errors.

One important source of deviation is the impedance associated with the row interface.

A reference column containing known impedances can be used for calibration.

By comparing the response of an unknown sensor with a known reference sensor in the same row, common error terms can be compensated.

This calibration approach was investigated through both simulation and hardware implementation.
